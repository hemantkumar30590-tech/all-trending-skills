# Contributing to Awesome Claude Code

Thank you for your interest in contributing! This list aims to be the most comprehensive and up-to-date resource for Claude Code projects.

## How to Contribute

### Adding a Repository

1. **Fork** this repository
2. **Add** your entry to the appropriate section in `README.md` (English) and `README_CN.md` (Chinese)
3. **Submit** a Pull Request

### Entry Format

```
| [owner/repo](https://github.com/owner/repo) | Xk ⭐ | One-line description of what it does |
```

### Requirements

- ✅ Directly related to Claude Code by Anthropic
- ✅ Public repository (not private)
- ✅ Has a README with clear description
- ✅ Active maintenance (last commit within 12 months preferred)
- ✅ Adds value not already covered by existing entries
- ❌ No spam, promotional, or low-quality repos
- ❌ No forks without significant changes

## Updating Star Counts

Star counts go stale. If you notice outdated counts, feel free to submit a PR updating them. Use the format `Xk ⭐` for thousands (e.g., `13.5k ⭐`).

## Reporting Issues

If a repository is:
- Abandoned or deleted
- Moved to a new URL
- No longer Claude Code related
- Duplicate of an existing entry

Please open an issue or submit a PR to fix it.

## Language Versions

Both `README.md` (English) and `README_CN.md` (Chinese) should be updated together when adding entries. The Chinese description should be a natural translation, not machine-translated verbatim.
